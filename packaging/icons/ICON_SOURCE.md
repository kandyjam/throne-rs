# Icon source

- Master crown: [`crown-upstream.png`](crown-upstream.png) — copied from upstream
  [throneproj/Throne](https://github.com/throneproj/Throne) `res/public/Throne.png`
  (green 3-peak faceted geometric crown).
- App tiles: light (white) / dark (`#0A0A0A`) rounded squares with dock-matched padding;
  crown composited from the master PNG (exact outline).
- Tray: monochrome silhouette of the same crown.
- SVG files are approximate edit helpers; PNG/ICNS/ICO are the shipping assets.
- Live copies: `crates/throne/resources/app-icon*`.
